SVM-IOA v2.0.6 双因子交互效应导出
发布日期：2026年11月15日

启动：解压后双击 SVM-IOA_v2.0.6.exe。打开已有项目后重新计算曲面即可。

在「分析中心 > 可视化分析」计算曲面后，「交互效应指标」卡片直接显示当前两个因子的红蓝交互等值图。切换因子、固定值或PDP计算方式后，图形与指标一并更新。
点击「导出交互效应 TIFF」可保存图形、H²、因子名称、计算条件和色标。所有PNG与TIFF图片按单张2,000,000字节设上限。
TIFF先尝试Deflate无损压缩。若编码仍超限，软件按比例缩小像素尺寸再重试。样例交互TIFF保持2760像素宽、300 dpi元数据，两种模式分别为515953和454507字节。

SVM-IOA v2.0.5 双因子交互效应导出
发布日期：2026年11月15日

启动：解压后双击 SVM-IOA_v2.0.5.exe。打开已有项目后重新计算曲面即可。

在「分析中心 > 可视化分析」选好两条坐标轴并计算曲面。「交互效应指标」显示这两个因子、固定取值或PDP样本平均口径，以及对应的H²。
点击「导出交互效应 TIFF」保存当前因子对的交互等值图，图中包含因子名称、计算条件、H²、响应变化幅度、最大预测响应及带单位色标。导出为无压缩RGB TIFF，宽2760像素，写入300 dpi元数据。
图中的交互分量等于中心化的双因子预测减去两个中心化的单因子效应。红色高于加性基线，蓝色低于加性基线，白色接近零。
固定因子模式下，分别计算两个单因子效应时，另一坐标轴均固定在其中点。本次修正后一项曾沿用前一轴终点的问题，因此同一个项目的H²可能与旧版略有差异。

SVM-IOA v2.0.4 TIFF图片导出版
发布日期：2026年11月15日

启动：解压后双击 SVM-IOA_v2.0.4.exe。可打开已有项目。

在「分析中心 > 迭代结果」选择每代统计、每次预测散点或历史最好值，点击「导出过程图 TIFF」。
在「分析中心 > 可视化分析」显示等值线图或3D曲面，点击「导出高清 TIFF」。
可以在TIFF和PNG之间任选。TIFF为无压缩RGB白底，写入300 dpi印刷分辨率。
曲面高清导出宽度至少2400像素。过程图的像素尺寸取决于当前画布和屏幕缩放。

7种视图的PNG和TIFF均已通过浏览器导出和独立解码检查。TIFF像素逐一匹配对应PNG以白色为底的呈现。
报告在「验证数据/v204-image-exports.json」。桌面EXE已编译，内嵌资源已与测试源码核对。

SVM-IOA v2.0.3 曲面与等值线读值版
发布日期：2026年11月3日

启动：解压后双击 SVM-IOA_v2.0.3.exe，原版EXE保留。
打开原项目，在“分析中心 > 可视化分析”重新计算曲面即可。
不需要重新训练已有的有效SVR模型或重新寻优。

如何读值
1. 看清两个轴的变量和“因子工具”里固定的其他因素。
2. 3D图点击曲面，选取所点面片最近的网格节点并高亮，显示其SVR预测值。
3. 图下方直接输入两个轴的精确数值，点击“查询预测值”，可查询任意轴范围内配比。
4. 切换2D等值线图后，可点击图内任意位置读值；等值线标签也是强度值。
5. 下方显示两个轴值、所有其他因素固定值、预测响应和单位。
6. 点击“清除选点”清除标记；导出高清PNG会保留选点和读值标签。

注意
3D透视可能遮挡，点击明确采用最近网格节点，提示“3D网格节点读值”。
若要查询严格6%、6%等指定配比，应使用数值输入，不要从透视图估计坐标。
固定模式用SVR对完整配比直接预测；PDP模式则计算全部样本其他特征取值下的平均预测，明确标注PDP。
曲面不自动套用寻优的总量约束。轴范围内的组合仍可能超出实测点凸包。
读值来自模型，不能当作材料实测；数字显示4位小数不代表模型具有同样的预测精度。
数据或模型变化时旧读值失效，需重新计算曲面。切换视角保留选点。

原有功能
保留v2.0.2的散点精确选取与点击高亮、每代统计、逐次预测、CSV/PNG及项目恢复。
原有18%总量项目的优化结果仍为1578.904367kPa。
Windows10/11 64位，.NET Framework4.8兼容环境与Edge WebView2。
升级前建议保存旧项目；沿用原WebView2用户配置以读取自动保存。
